# 💼 Personal Portfolio Website

This is a responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. The website showcases my profile, technical skills, and projects, and includes a contact form for collaboration opportunities.

## 🚀 Live Demo

🌐 [View Live](https://pritam-portfolio-website.netlify.app/)

## 📁 Project Structure

Portfolio-Website/
├── index.html
├── style.css
├── script.js
├── assets/
│ └── images, icons, etc.
└── README.md


## 🧩 Features

- 🏠 **Home Section** – Introduction with name, tagline, and call-to-action button.
- 👤 **About Section** – Brief bio and overview of my background.
- 💡 **Skills Section** – Lists technologies and tools I'm proficient in.
- 🧪 **Projects Section** – Highlights selected projects with links and descriptions.
- 📬 **Contact Form** – Visitors can submit a form to get in touch.
- 📱 **Responsive Design** – Fully functional on desktops, tablets, and smartphones.
- ✨ **Smooth Transitions** – Clean scroll effects and button hover animations.

## 🛠️ Technologies Used

- **HTML5** – Semantic layout and structure.
- **CSS3** – Custom styling, Flexbox, Grid, and media queries.
- **JavaScript** – DOM manipulation and interactive components.
- **Netlify** – Deployed and hosted the live version.

## 📌 How to Use Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pritamchaudhary/Portfolio-Website.git
   
2. Navigate to the project directory:
   cd Portfolio-Website

3. Open index.html in your preferred browser or live server.
